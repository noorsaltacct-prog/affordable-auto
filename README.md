# Affordable Mobile Mechanic MC LLC

Static Vercel-ready website for Mark Casias, Lubbock TX.

## Deployment
Import the folder into Vercel as a static Other framework project, or deploy using Vercel CLI. No build command is needed. Keep assets/gallery and assets/logo.png together with index.html.

## Content
34 real customer-supplied repair photos, 18 customer-supplied MP4 clips, and 18 locally generated video poster frames. The hero and service images use the client's real supplied photos.

## Important
The quote form composes an SMS to +18065004719; it does not transmit or store form data. Prices were not provided and are intentionally not invented. Service coverage is approximately 20 miles around Lubbock, subject to confirmation by the business. The supplied materials state no motor or transmission rebuilds. No testimonials were fabricated.
